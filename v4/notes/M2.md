# M2 building blocks: result

*2026-10-14. Follows [M2-M4-plan.md](M2-M4-plan.md) §3. Verified by eye on web (built-in
browser pane, Chrome, DPR 1) and the iOS simulator (iPhone 18 Pro, DPR 3). Screenshots and
contact sheets are in the session scratchpad, not in the repo.*

## Verdict

**The gallery passes §M2.11 on web and iOS.** All three checkpoints passed and none of the
fallbacks was needed: contacts work, so flush-only authoring stays an authoring rule, not a
fallback. Two pipelines in one pass work with a raw `GPURenderPassEncoder` and
`pipeline.with(pass)`, which is stable API.

## What was built

- **Geometry (`geo/`).**
  - JSON `GeoSpec` → `buildGeo` → a cached prototype (mesh, topology, its own line sets).
  - `extrude`: rect, rounded rect, circle, polygon (ear clipping), sector or pie, plus seams.
  - `box` is now a wrapper on `extrude`.
  - `lathe`: seams, default steps, `sphereProfile`, smooth poles.
  - `tube`: closed planar loops, `bend: 0`, and a per-vertex centreline tangent.
  - `belt`: outer tangents plus wrapped arcs.
  - `contact`: triangle-triangle crossings.
  - `marks`: `boltCircle` and `polyline` helpers.
- **SceneStore (`scene/store.ts`).**
  - Node types: groups (with `moves`: `spin`/`set` handles), parts, pools (`count`, `pose`, `style`), marks.
  - Tokens make re-registration under React safe.
  - `build()` gives one static batch (instance slot per part) plus one batch per pool. Open meshes go in their own batch.
  - `flatten()` writes the instance table and recomputes only below changed nodes.
- **Renderer.**
  - Tables: Instance, Style, Mark, and a vertex with a tangent.
  - Rebuilds when `store.version` changes; uploads instances only when they are dirty.
  - One pass: fill batches (culled, plus an unculled batch for open meshes), then marks.
- **Tone rules.**
  - Plan rule: the kit's extrude bins, AA'd. Used only while the model's z axis stays vertical.
  - Tube rule: the kit's shine and shade stripes, along the interpolated centreline tangent. It hands over to bands when the tube is seen end-on.
- **Marks.**
  - Dots and round-capped segments in screen space, depth-tested.
  - Each quad sits on the mark's tangent plane.
  - Facing fade, hidden on back sides, opacity by tone, the new `dot` palette slot, cyan in debug view 1.
- **App.**
  - Blocks in `apps/app/src/blocks/`: `Scene`, `Group`/`Machine`, `Box`, `Extrude`, `Lathe`, `Tube`, `Belt`, `Instances`, `Marks`, `useFrame`, `useNode`.
  - The shell ticks the store with dt clamped to 0.1 s.
  - Scene chip: `gallery` and `m1`.
  - Dev hooks: `__v4.setScene`, `setPoolCount`, `look`, `store()`.
- **Gallery (`apps/app/src/gallery/`).** Six rows (m1, ext, lathe, inst, marks, contact), with pair views and close-up views.

## Fixes made during the by-eye pass

1. **Tube stripes jagged.** The across-tube direction came from the screen derivatives of v. Those are perpendicular to the projected ring chords, not to the tube axis. Tubes now carry a per-vertex centreline tangent, and the axis is projected per pixel.
2. **Open pipe ends showed paper** (inner walls culled). Open meshes now go in an unculled batch, and back faces shade as an `s0` void with no lines.
3. **Sphere pole speck.**
   - Cause: the spline met the pole with the chord slope, which made a tiny cone tip.
   - Fix: poles next to smooth knots close with a horizontal tangent, and pole normals are the axis.
   - Also: the contour's facing gradient is now computed per triangle in the vertex stage, not with `dpdx`/`dpdy`.
4. **Dots cut in half** on sloped faces. The marks quad now lies on the mark's tangent plane. Contact lines, which have no normal, are lifted by their own size.
5. **Fringed contact curves** (butt-ended short segments): segments now use round caps.
6. **Gallery fit too loose.** The world AABB of a diagonal layout is a big diamond on screen. Fits now use the corners of each part's box.

## Deviations from the plan

- **The M1 row keeps `tone: 'bands'` on its tube**, so it stays a regression check. The tube rule is shown in the lathe and contact rows.
- **Sector angles are in degrees.**
- **`Bounds` carries an optional `points` hull** for fitting.
- **Mark segments use round caps.** Overlapping caps at chain joints can bead slightly when a line is thinner than a pixel (alpha < 1); at DPR 3 lines are wider than a pixel, so iOS is unaffected.
- **`store.group$` / `store.pool$`** are typed shortcuts for `node()`.
- **Pools draw `count` instances.** Instance visibility flags also hide marks of hidden instances.

## Known gaps (for M3+)

- **Tube rule on tight turns seen nearly end-on** (the left and right of a horizontal ring) still shows faint streaks inside the hand-over band.
- **The contour term still over-widens at saddles** (comment in `shaders.ts`).
- **Close-up views are zoom × the gallery's fit**, so their lines get very thick (Decision 3: widths scale with zoom).
- **Fast Refresh of a scene module remounts the root** (new GPU device). It is fine, but slow on iOS (the first Hermes build takes about 0.5 s).
- **Reduced motion** is plumbed into `store.motion.reduced`, but nothing uses it yet (M4).
